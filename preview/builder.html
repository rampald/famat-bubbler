How to format an upload — exact columns and example

State Convention file format

Provide Student Name and the nine-digit No Team State ID, then the student's Individual, Round 1, and Round 2 tests. All three test assignments are required for every attendee.

  1. Put the column names in the first row and use one student per row. CSV, tab-separated text, and rows copied from a spreadsheet are accepted.
  2. Keep every Student ID as exactly nine digits. It must be the No Team ID ending in 0. In Excel or Google Sheets, format the ID column as plain text so a leading zero is not removed.
  3. Use an event's full name or its three-digit code exactly as shown in the event catalog and code editor. The importer stops on unknown or ambiguous event names.
  4. School and School Code are optional; State Division and Topic Eligibility Level are required. Use School when one file contains more than one school; otherwise the default school name above is used. A supplied four-digit School Code must match the first four digits of the Student ID.
  5. Put quotation marks around a name containing a comma, for example "Rivera, Ana". Leave unused optional-event cells empty; do not enter dashes or “N/A.”
  6. PDFs must contain selectable text. A scanned image or photo-only PDF cannot be read and will be blocked instead of silently skipped.

Accepted header row: School, School Code, Student Name, Student ID, Division, Individual, Round 1, Round 2

Copyable CSV example:

School,School Code,Student Name,Student ID,Division,Individual,Round 1,Round 2
Sample Academy,1234,Jordan Lee,123400240,Alpha,Alpha Individual,Trigonometry (Alpha),Complex Numbers (Alpha)

Header capitalization and common variants such as State ID are accepted. Extra columns are reported, and any column or event name the program cannot recognize is flagged for review.
