The roster says a different school. Which name goes on the scantrons?

1. Paste your famat.org roster

Copy the roster page or the Students page from famat.org (or open the roster PDF) and paste it all here, header lines included. You can paste the high school and middle school rosters together. A CSV with Name and ID also works.

Optional: last year's roster

2. Check the list

Topic tests

Pick each division's topic test once, or leave "Name and ID only" so students bubble the test code at the test.

Tick students to change or delete several at once. Shift-click to tick a range.

3. Print

Print at Actual size (100%), single-sided, on a good laser printer. Check that the corner marks and bubbles print dark before printing the whole stack.
